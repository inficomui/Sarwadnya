# Admin Revoke/Delete Investment Implementation Guide

This guide details the backend logic required to implement the "Delete/Revoke Investment" functionality. This is critical for reversing accidental approvals and ensuring data integrity.

## Endpoint Specification

- **Method**: `DELETE`
- **URL**: `/api/admin/transfers/{id}/delete`
- **Access**: Admin Only (`auth:sanctum`, `admin` middleware)

## Logic Flow

When an admin deletes an approved investment, the system must perform a **Cascading Delete** to remove all generated data and revert financial impacts. This operations **MUST** be wrapped in a database transaction.

### Step-by-step Implementation (Laravel)

1.  **Start Transaction**: `DB::beginTransaction()`
2.  **Find Transfer**: Retrieve the transfer/investment record by ID.
3.  **Reverse Referral Commissions**:
    -   Find who referred the user (if any).
    -   Find the commission transaction records linked to this investment.
    -   **Deduct** the commission amount from the referrer's wallet.
    -   Delete the commission transaction records.
4.  **Delete Payout Schedules**:
    -   Find all `Payout` records linked to this investment (ROI, etc.).
    -   Delete them.
5.  **Revert User Wallet (If applicable)**:
    -   If the investment amount was deducted from the user's `Wallet`, decide if you want to refund it.
    -   *Scenario A (Mistake Approval)*: If the user never actually paid (fake proof) and you approved by mistake, **DO NOT refund**.
    -   *Scenario B (Refund)*: If you are cancelling a valid investment, you might want to refund the capital to the user's wallet.
    -   *Recommended for "Mistake Approval"* : Assume the money never existed. **Do not refund** to wallet unless it was a wallet-based activation. If it was a "Bank Transfer" proof approval, deleting it effectively says "we never received this money".
6.  **Delete Investment Record**: Remove the entry from the `investments` table.
7.  **Delete/Update Transfer Record**: Delete the `transfers` record or mark it as `deleted`.
8.  **Commit Transaction**: `DB::commit()`

## Example Code (Laravel Controller)

Values such as `WalletTransaction` or `Payout` models are assumed based on standard patterns.

```php
public function destroy($id)
{
    try {
        DB::beginTransaction();

        // 1. Find the Transfer/Investment Request
        $transfer = Transfer::with(['investment', 'user'])->findOrFail($id);

        // 2. Handle Associated Investment Data
        if ($transfer->investment) {
            $investment = $transfer->investment;

            // A. Reverse Referral Commissions
            // Find commissions generated by this investment
            // Assuming you have a 'source_id' or 'reference_id' in WalletTransaction linking to investment
            $commissions = WalletTransaction::where('type', 'referral_commission')
                                            ->where('reference_id', $investment->id) // link to investment
                                            ->get();

            foreach ($commissions as $commission) {
                // Deduct from referrer's wallet
                $referrerWallet = Wallet::where('user_id', $commission->user_id)->first();
                if ($referrerWallet) {
                    $referrerWallet->balance -= $commission->amount;
                    $referrerWallet->save();
                }
                // Delete the transaction record
                $commission->delete();
            }

            // B. Delete Payout Schedules (ROI)
            Payout::where('investment_id', $investment->id)->delete();

            // C. Delete the Investment Entry
            $investment->delete();
        }

        // 3. Delete the Transfer Record
        $transfer->delete();

        DB::commit();

        return response()->json([
            'status' => 'success',
            'message' => 'Investment and all related data deleted successfully.'
        ]);

    } catch (\Exception $e) {
        DB::rollBack();
        return response()->json([
            'status' => 'error',
            'message' => 'Failed to delete investment: ' . $e->getMessage()
        ], 500);
    }
}
```
