# Sarwadnya Finance

This repository contains two main projects for the Sarwadnya Finance system:

## Projects

1.  **Client**: A Next.js based web application.
    - Located in the `/client` directory.
    - To run: `cd client && npm install && npm run dev`

2.  **Mobile**: An Expo/React Native based mobile application.
    - Located in the `/mobile` directory.
    - To run: `cd mobile && npm install && npx expo start`

## Setup

- Ensure you have Node.js installed.
- Install dependencies for each project separately.
- Environment variables should be configured in their respective project directories.
